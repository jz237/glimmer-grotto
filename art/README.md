# Art sources

The source images in this directory were generated with the built-in OpenAI
image-generation workflow for Glimmer Grotto. Production derivatives are
resized and optimized under `public/` so the install icon and social card do
not impose their source-resolution transfer cost on players.

- `heartbloom-icon-original.png`: six-petaled Heartbloom app-icon source.
- `glimmer-grotto-social-original.png`: landscape social-preview source with
  Mica, Luma, the Heartbloom, and the title “GLIMMER GROTTO”.
